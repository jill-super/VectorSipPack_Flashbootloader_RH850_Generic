## Purpose

vFlash downloads application/calibration data to an ECU running this bootloader. The delivery ships an **OEM-specific template installer** (`vFlashTemplateInstaller_Vector_SLP3_AddressBased.exe`) plus seed/key material (`seedkey.dll`, `seedkey.zip`) matching the demo's `Sec_SeedKeyVendor.c`.

> The vFlash tool itself is not part of the delivery and must be purchased separately (see [Project Info](../../sip/general/readme-cbd1701035/) §2).
