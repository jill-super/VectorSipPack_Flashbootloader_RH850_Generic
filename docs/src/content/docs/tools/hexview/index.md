## Purpose

HexView (`hexview.exe` + `expdatproc.dll`) is the hex-file viewer/editor and **post-build tool**: it computes checksums/CRCs, creates signatures and validation structures, encrypts the flash-driver image (`BSW/Flash/flashrom.*`), and converts between HEX/SREC/VBF and other formats. Example configs and logs ship in `_examples/`; the checksum plug-in source pattern is in `_expdatproc/` (`expdat_csum.c`, `expdat_datproc.c`, …).
